What are Git and Github

Git: The tool

Git is a version control tool. It records snapshots fo changes to a project's files so that you can track what changed, when you changed it, and return to an earlier version.

GitHub: The website

GitHub is the website that hosts Git repositories online. You can share projects, collaborate, and keep another copy on a remote repository.

Repository (repos)

A repository contains your project and its Git history. A local repository is on your computer, while a remote one can be on GitHub.
