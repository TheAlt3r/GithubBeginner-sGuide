What are Git and GitHub?

Git: The tool

Git is a version control tool. It records snapshots of changes to a project's files so that you can track what changed, when you changed it, and return to an earlier version.

GitHub: The website

GitHub is the website that hosts Git repositories online. You can share projects, collaborate, and keep another copy in a remote repository.

Repository (repos)

A repository contains your project and its Git history. A local repository is on your computer, while a remote one can be on GitHub.

Commit and push, step by step

These steps use GitHub Desktop.

Step 1: Create a repository

Open GitHub Desktop and select File & New repository. Give it a name, choose where it will be saved on your computer, and create it.

Step 3: Review the changes

Go back to GitHub Desktop and click the Changes tab. Review the changed files and select the ones you want to include in your commit. Do not include passwords or private keys.

Type a short message in the Summary box explaining what you changed. Then click Commit to main (or the name of your current branch). The commit is saved locally.

Mistakes beginners often run into

Forgot to push

You committed your work, but nothing changed on GitHub.

Fix: Check GitHub Desktop for Push origin and push your commits.

Changes do not appear

You edited a file, but GitHub Desktop does not show it.

Fix: Save the file and check that you opened the correct repository and branch.

Accidentally included a secret

A password or token was added to a commit.

Fix: If you pushed a real secret, immediately revoke or rotate it. Read the security guide for next steps.

Push was rejected

GitHub may have changes that your local branch does not have yet.

Fix: Fetch and pull the latest changes, review any conflicts, and then try pushing again.
